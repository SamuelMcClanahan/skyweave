### D6-F1 — covariance collapse from residual-variance scaling

Mechanism: the D1 measurement covariance is the inverse weighted
normal-equations matrix SCALED BY the robust residual variance. With
3 cameras that variance is estimated from 2N-3 = 3 degrees of
freedom, so it fluctuates wildly batch to batch. On a batch whose
residuals happen to be small, the reported covariance collapses, the
EKF over-trusts that measurement, P shrinks, and the published state
is confidently wrong. This is the tail consequence of the coverage
shortfall already recorded in the D1 hand-back.

Evidence: the zero-magnitude regime — NO fault injected — still
produces 0 events (0.000 of confirmed
publications). D1 exposed `residual_variance_floor` as the config
lever; moving it is out of scope for this phase.

### D6-F2 — the systematic channel is never populated

Mechanism: D0 section 5 requires every LocalizationResult to carry a
`systematic_bound` with source labels, reported beside the
conditional covariance. The shipping chain leaves it at (0, 0, 0)
with no sources — verified on a clean run. The conditional
covariance is DEFINED to exclude bias, so a calibration error
produces a state that is confidently wrong with nothing in the
output flagging it: the two-channel rule is half-implemented.

Evidence: Tier III (calibration) axes dominate the table below.
Consequence if shipped: calibration drift in the field yields a
confidently wrong track that no consumer can detect from its own
output — the exact failure the two-channel rule exists to prevent.
