# D1 Monte Carlo error budget

**Label: every number in this document is Modeled.** Synthetic scene,
modeled noise, no bench data. Nothing here is Measured.

Generated by `uv run python -m skyweave2.geometry.budget --seed 7 --out docs/D1_ERROR_BUDGET.md` (deterministic; identical bytes for identical seed).

## Scene and method

- Target at 243.84 m (800 ft) due north of a linear east-west
  array of 3 cameras aimed at the target; world ENU, line of
  sight = +y, cross-range = x/z.
- FOV 60.0 deg horizontal (Provisional per D2 partial freeze),
  resolution 2304x1296, focal length 1995.3 px.
- N = 1000 trials per cell, seed 7, per-cell child seeds in fixed order.
- Estimator: Huber (1.5 px) Gauss-Newton with Levenberg
  damping on pixel reprojection residuals; covariance = inverse weighted
  normal equations scaled by robust residual variance (frozen D1 decisions).
- Random axes (centroid noise, per-camera timing jitter) are drawn per trial
  and test covariance coverage. Pose axes perturb the estimator's calibration
  against a fixed truth: pure systematic bias, reported as sensitivity curves,
  never folded into covariance (two-error-channel rule).
- Range error = |error along y|; cross-range error = sqrt(ex^2 + ez^2).
- Coverage = fraction of trials whose Mahalanobis distance^2 against the
  reported covariance falls inside the 3-dof chi-square quantiles 3.53 / 8.02 / 14.16.

## Q3 — where depth is too weak to report

- Solver weak-geometry gate: triangulation angle < 0.50 deg or condition > 100000000.
- At 243.84 m range that angle gate corresponds to a total
  baseline of about 2.1 m: below that, results return
  `WEAK_GEOMETRY` and must not be consumed as confident points.
- Max pairwise triangulation angle per swept baseline: 5 m -> 1.17 deg, 10 m -> 2.35 deg, 25 m -> 5.87 deg, 50 m -> 11.71 deg.
- No swept cell tripped the gate (weak fractions in Tables A/B). The
  practical boundary inside the sweep is accuracy, not the gate: cells with
  range p95 above 5 m in Table A: (5 m, 0.50 px), (5 m, 1.00 px), (5 m, 2.00 px), (10 m, 1.00 px), (10 m, 2.00 px), (25 m, 2.00 px).

## Coverage finding

Reported-covariance coverage under pure centroid noise sits below the
nominal 68/95/99.7% masses (Table A). Cause: with 3 cameras the robust
residual variance that scales the covariance is estimated from only
2N - 3 = 3 degrees of freedom, so the Mahalanobis statistic is
F-distributed rather than chi-square (heavier tail). This is a property
of the frozen scale rule at small camera counts, not an estimator bug;
coverage tightens as cameras are added. Candidate remedy if D5 needs
calibrated gates at N = 3: floor the residual variance at 1.0
(`GeometryConfig.residual_variance_floor`), which makes coverage
conservative instead of optimistic.
