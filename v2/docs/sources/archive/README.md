# Source archive

No external PDFs or SDK files are vendored here yet.

Before adding an artifact:

1. confirm redistribution terms;
2. use the official URL and exact document/revision ID;
3. record retrieval date, byte size, and SHA-256 in `../manifest.yaml`;
4. keep proprietary SDKs and large binary trees out of git;
5. prefer a link when an authoritative stable source remains available.

Current archive candidates are the BNO055 datasheet, ZED-F9P product summary
and integration manual, and FAA AC 20-165B. They remain linked in the manifest
until archival is explicitly approved.
